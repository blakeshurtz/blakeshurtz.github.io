# ChatGPT prompt to generate favicon files

Use this prompt in ChatGPT (or another image-capable model) to generate the site favicon set.

## Prompt

Create **4 PNG favicon files** for my personal portfolio site.

Style requirements:
- Clean, professional, minimal design
- Works on both light and dark browser tab themes
- Should remain recognizable at very small sizes (especially 16x16)
- Prefer a simple monogram ("B"), abstract mark, or geometric symbol in blue/white tones
- No tiny text besides a possible bold single-letter monogram

Output requirements:
- Transparent or solid background (your choice, whichever gives best legibility in tabs)
- Export these exact files and sizes:
  1. `favicon-16x16.png` (16x16)
  2. `favicon-32x32.png` (32x32)
  3. `favicon.png` (32x32; same visual as favicon-32x32 is fine)
  4. `apple-touch-icon.png` (180x180)

File quality requirements:
- PNG format only
- Crisp edges, no blur
- Pixel-fit the 16x16 version so it looks clear in browser tabs

## Where to save them in this repo

Save all 4 files in:

`img/`

Final paths should be:
- `img/favicon-16x16.png`
- `img/favicon-32x32.png`
- `img/favicon.png`
- `img/apple-touch-icon.png`
